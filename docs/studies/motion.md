# Motion — Case Study

**Brief.** Motion is a file of self-set studies, not a commission. Each study takes one visual idea and pushes it until the motion breaks: abstract form, procedural movement, and type drawn from repeating marks. The tools were After Effects, Photoshop, and Blender. There was no client brief and no delivery date. The point was to test a technique at speed and keep the result, so the file grew as a set of experiments rather than a body of finished work.

**Process.**

1. Each study opens with one form or one rule, not with a finished frame.
2. Type and shape were built in After Effects or Blender, then finished in Photoshop for grain and print texture.
3. The surviving still shows the method: a thin wave line sits above a letterform that fills from the top with a striped field, then turns into a dot grid at the base.
4. The work is designed as a loop, so the first and last frame have to match before the study counts as done.
5. The same form was reused at different densities, which is how one idea produced a short series rather than a single frame.
6. The export is a still. No loop survives in the project file today, so the case shows the still only.

**Result.**

- One exported still survives in the project file. The number of studies in the set is unconfirmed.
- The source still is 720 x 540 pixels and 209 KB on disk, at assets/images/motion.png.
- The three case images, the still and two detail crops, total 430 KB.
