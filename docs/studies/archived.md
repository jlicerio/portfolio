# Archived Works — Index Hub

**Brief.** This page indexes the studies on the site in one place. It covers 2022 to 2026 and links each entry to its page. The hub groups the same twelve studies by year, so the same set can be read two ways: by kind of project, and by date. Nothing here is a new piece. The value is the map: twelve studies, four years, one link per study, and no dead ends.

**Process.**

1. Every entry is a project already on the site. No image on this page is new.
2. Rows are grouped by year, newest first: 2026, 2025, 2023, and 2022.
3. Each row carries a number, a title, a one-line summary, the discipline, the year, and a thumbnail.
4. The list is built from the site data file when the page loads, so one record feeds the work index, this index, and the study page.
5. Rows reuse the work-index component from the Work page, so the type scale, the hover state, and the thumbnail crop match the rest of the site.
6. A study is added with a record in the site data file and a page from the shared shell. Every list reads that one record, so the title, the discipline, and the year cannot drift. Each index numbers its own rows: Work counts down the sections, this index counts down the years.
7. The row preview is a gallery wall of framed works from the archive. The venue is unconfirmed.
8. Six clips from the archived pieces sit above the index, each with a poster frame. The player loads only when a clip is pressed.
9. The page opens on the work index row for this study, then numbered rows, the same layout as every other study page.

**Result.**

- Twelve studies indexed: four from 2026, three from 2025, three from 2023, and two from 2022.
- Year range 2022 to 2026, read from the project records.
